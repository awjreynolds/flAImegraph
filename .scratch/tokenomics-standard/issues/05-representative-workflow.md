# Which ticket workflow should test the existing standards?

Type: grilling
Label: wayfinder:grilling
Status: open
Assignee: none
Parent: ../map.md
Blocked by: 04

## Question

Which representative workflow and existing evidence should anchor a fit assessment of current and emerging standards? The user's motivating case includes a ticket with multiple conversations, delegated subagent work, and an epic rollup. Establish what result the current workplace analysis is unable to provide and which observations are available before selecting an integration or proposing any extension.

The output is a concrete evaluation scenario and success criteria, not a new format. Facts available in the environment should be investigated rather than requested from the user; private workplace details and desired interpretation require the user's own input.

## User clarification

Per-agent totals alone do not meet the requirement. The workflow must expose internal activity and support detailed drill-down and aggregation. A representative trace should include multiple model calls, tool use, and delegation; context reuse, retries, and compaction are candidate stress cases where available. [Detailed analysis readiness](../../../docs/research/deep-analysis-readiness.md) distinguishes the confirmed depth requirement from proposed acceptance cases. The exact trace and first harness remain unselected.
