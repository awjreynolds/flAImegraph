## Question

Given actual captured evidence, which views should report measured operation usage, which may report estimated context-source shares, and how should unknown or shared attribution appear? Set the minimum depth that answers the user's analysis questions without equating temporal adjacency with causation or counting the same usage under multiple operations. Reuse established accounting and profiling semantics where they apply; agree the first validation criteria with the user.

## Proposed resolution, awaiting user review

Under the instruction to progress autonomously, the working policy is: observed per-response usage, derived rollups, explicitly estimated context-source shares with residuals, and separately labelled counterfactual comparisons. No temporal-proximity cost attribution. Missing quantities are not zero. [Implementation route](../../../docs/research/implementation-route.md) records the concrete proposal. This policy supports independent work; the user has not yet accepted the interpretation of the resulting profile.
