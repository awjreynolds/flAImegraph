# flAImegraph

Evidence-backed analysis of agent work: monetary cost flame graphs, model usage, context growth, tool activity and delegation.

The project is in research and implementation planning. The aim is detailed drilldown from an epic or ticket to recorded operations and model responses, with accounting that survives regrouping. Existing telemetry, financial and profile standards are the starting point; this project is not proposing a competing standard.
