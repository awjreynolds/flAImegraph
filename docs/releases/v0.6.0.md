# v0.6.0 — Portable logging and native capture

Released 9 September 2026 through [GitHub Releases](https://github.com/awjreynolds/flAImegraph/releases/tag/v0.6.0).
The local logging toolchain supports the documented Codex and Pi surfaces;
Claude capture and imports remain experimental. See the [support matrix](../ga-readiness.md#release-support-matrix),
[validation evidence](../implementation-evidence/logging-ga-candidate.md) and
[migration notes](../../CHANGELOG.md).

## Install the CLI

Download `flaimegraph-0.6.0.tgz` and `SHA256SUMS` from the release. Verify the
archive against its checksum using `sha256sum` (Linux) or `shasum -a 256` (macOS).
With Node 22 or 24:

```sh
npm install --global --ignore-scripts ./flaimegraph-0.6.0.tgz
flaimegraph schema --kind usage --out usage.schema.json
flaimegraph demo --out-dir usage-demo
```

Installation fetches dependencies from npm. The package itself is distributed
as a GitHub asset, not published to the npm registry. Perl is required for SVG
rendering. After installation, saved-log imports, validation, reports and profile
exports run locally without provider credentials. A child harness launched by
`capture` retains its own provider access, permissions and billing.

## Run the static viewer

Download `flaimegraph-usage-explorer-0.6.0.tar.gz` and verify its checksum. Extract
it into a new directory and serve it locally:

```sh
mkdir flaimegraph-viewer
tar -xzf flaimegraph-usage-explorer-0.6.0.tar.gz -C flaimegraph-viewer
python3 -m http.server 8080 --bind 127.0.0.1 --directory flaimegraph-viewer
```

Open `http://127.0.0.1:8080` and select **Load a session**. Files are processed
locally in the browser. The archive includes static route entry points for usage,
context and operations. This release does not change the separately hosted private Site.

## Changes and limits

- Four portable Draft 2020-12 schemas, 23 conformance cases and an independently
  executable Python syntax verifier accompany the reference semantic validators.
- Native capture saves atomic metadata snapshots and exposes child failures and
  incomplete output. Snapshots replace earlier views; do not merge them. Use the
  opt-in lifecycle journal for its stronger documented persistence contract.
- Pi JSON-mode receipts, timestamps and tool identities are corrected. Reimport
  original affected logs as replacement datasets; do not merge old and corrected imports.
- Codex exec totals remain aggregate checks without response-level attribution.
  Claude has fixture and authentication-failure evidence, with no successful live run.
- The viewer adds native formats, readable observation columns and patched dependencies.

Package version 0.6.0 preserves usage schema 0.4 and lifecycle schema 0.5. Product
availability does not establish an industry standard, independent adoption,
complete billing coverage or demonstrated improvement in accepted work.
